### 🚀 Featured Open-Source Project

#### **[`go-ttdb`](https://github.com/chuongnx/go-ttdb)** — Go `database/sql` Driver for Oracle TimesTen
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![Go Reference](https://pkg.go.dev/badge/github.com/chuongnx/go-ttdb.svg)](https://pkg.go.dev/github.com/chuongnx/go-ttdb)

Bridging a long-standing gap in the Go ecosystem, **`go-ttdb`** is the first community-driven, open-source Go `database/sql` driver engineered specifically for **Oracle TimesTen In-Memory Database**.

* **Standard Compliance:** Seamless integration with Go's native `database/sql` interface.
* **High-Performance Connectivity:** Designed to leverage TimesTen's ultra-low-latency architecture (Direct Linked & Client/Server modes).
* **Enterprise-Ready Licensing:** Distributed under the **Apache License 2.0** for safe adoption in production and commercial environments.
